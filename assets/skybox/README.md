# Space background

These six unmodified NASA/Tycho star-map cube faces are CesiumJS's default
Earth skybox, used by God's Eye View through its standard Cesium viewer.
The atlas renders them locally behind its Space Engineers GPS map.

Source: https://github.com/CesiumGS/cesium/tree/1.124/packages/engine/Source/Assets/Textures/SkyBox

Credit: NASA / Goddard Space Flight Center Scientific Visualization Studio.
https://svs.gsfc.nasa.gov/3572/
